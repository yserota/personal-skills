What is it?

A Cursor Skill + automated pipeline

The Skill (/manage-my-day)

A Cursor Agent Skill that reads your pre-ingested data files, enriches them live with Jira and Confluence via MCP, sends everything to Claude with a structured prompt, then renders a five-panel React canvas inside the IDE.

TRIGGER User says "manage my day", "plan my day", "daily briefing"…
OUTPUT Live canvas opens beside the chat — updated each run

The Pipeline (automated)

Four Python scripts + one Google Apps Script collect raw data each morning. Windows Task Scheduler runs the orchestrator at 08:05. By the time you open Cursor, everything is ready.

New Feature — Draft Emails Panel

Inbox zero, one reply at a time

How it works

  • Claude scans your emails and action items during the normal analysis step — no extra LLM call
  • Drafts replies to incoming emails that need a substantive response (human sender, waiting on you)
  • Drafts outgoing emails for action items that involve contacting someone — follow-ups, team notifications, meeting invitations
  • Max 5 drafts per run, sorted by urgency
  • Auto-generated notifications, calendar invites, and Jira/GitHub activity emails are silently skipped

Under the Hood

Key technical decisions

Apps Script + Drive sync (no GCP needed)

Gmail and Calendar are exported by a Google Apps Script that runs inside Google Workspace — no GCP project, no OAuth app to manage. Files land in Drive, which syncs locally via Google Drive for Desktop.

MCP Policy Broker for Jira + Confluence

The skill uses jira_search and confluence_search through the existing MCP Policy Broker — the same tools already available in Cursor. Zero extra auth setup required.

Structured XML prompt engineering

All inputs are wrapped in named XML tags (<calendar>, <gmail>, <jira>…) before sending to Claude. This makes Claude's extraction reliable and parseable into canvas sections.

Graceful degradation everywhere

Missing files, failed Jira queries, Slack rate limits — every failure mode is handled silently. The pipeline never breaks because one source is unavailable. gemini_notes.txt is always optional.

Canvas stays outside the repo

The generated day-manager.canvas.tsx is written to Cursor's managed canvases/ directory — never committed to git. The template is version-controlled; daily output is ephemeral.

Corporate VPN / SSL compatibility

The truststore package injects the system certificate store into Python's SSL layer — solving the common issue where Slack SDK's bundled certs fail behind a corporate proxy.

Setup & Extensibility

Built to be shared and extended

Setup (one-time)

  • Copy the Apps Script to your Google account → deploy
  • Create a Slack bot, add channels to .env
  • Install Python deps (pip install -e .)
  • Register run_ingest.ps1 in Windows Task Scheduler
  • Copy SKILL.md to your Cursor skills folder
Full guide in SETUP.md

Easy to extend

  • Add a new Slack channel: one line in .env
  • Add a new data source: write an ingest_*.py script, add to ingest_all.py
  • Change the canvas layout: edit the template TSX
  • Add a new MCP tool: extend Step 2.5 in SKILL.md
  • Change the briefing format: edit the Claude prompt in Step 3
